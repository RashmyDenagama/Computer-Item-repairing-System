# Computer-Item-repairing-System
This is a computer item reparing system that is being built for the PPA module of the second year second semester.This is Built using React,SpringBoot and MySQL as for the technology stacks.It enables the customers to view the repaireed items and can make an appointment to the admin to repair the computer itrm.The admin previllages are that admin can view,delete and update the Appoints that the customers have made and can add items into the system.
Technology stacks ---> React ,SpringBoot,MySQL
